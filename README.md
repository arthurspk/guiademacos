## :dart: O guia para alavancar a sua carreira

> macOS é o sistema operacional da Apple e o ambiente de trabalho de boa parte dos times de desenvolvimento — front-end, mobile (iOS/Swift é exclusivo dele), dados e DevOps. Dominar o Terminal, o Homebrew, o gerenciamento de versões de linguagens e as ferramentas de produtividade certas transforma um Mac "de fábrica" numa máquina de programar de verdade. Este guia reúne documentação oficial, ferramentas, dotfiles de referência, comunidades e um capítulo dedicado a usar IA na prática para configurar e manter seu ambiente — tudo verificado e organizado para quem está montando o primeiro setup ou querendo modernizar o atual.

## 🗺️ Roadmap

Não existe um roadmap oficial único de "macOS para desenvolvedores" — a Apple documenta o sistema, e a comunidade documenta como configurá-lo para trabalhar. Este guia junta as duas pontas.

- [macOS — visão geral e novidades (Apple Developer)](https://developer.apple.com/macos/) — Página oficial com as novidades de cada versão do sistema.
- [Notas de versão do macOS (Apple Developer)](https://developer.apple.com/documentation/macos-release-notes) — Changelog oficial de cada versão, incluindo mudanças que afetam quem desenvolve.
- [Apple Silicon — documentação oficial](https://developer.apple.com/documentation/apple-silicon) — Como os chips M1–M4 mudam compilação, virtualização e performance para quem programa.

**Trilha resumida** (siga na ordem; cada etapa tem recursos nas seções abaixo):

1. **Terminal e shell** — entenda o Terminal.app (ou um substituto), o zsh (shell padrão desde o macOS Catalina) e o básico de navegação e permissões Unix.
2. **Gerenciador de pacotes** — instale o [Homebrew](https://brew.sh/) e aprenda a usar `brew install`, `brew bundle` e um `Brewfile` para reproduzir seu setup em outra máquina.
3. **Xcode Command Line Tools** — `xcode-select --install`: é o compilador C/C++, o `git` e boa parte das dependências de build que outras ferramentas esperam encontrar.
4. **Gerenciamento de versões de linguagem** — pare de instalar Node/Python/Ruby "direto no sistema": use `asdf`, `pyenv`, `nvm` ou `fnm`.
5. **Dotfiles** — versione `.zshrc`, `.gitconfig` e configurações do editor num repositório próprio; use `chezmoi` ou `stow` para sincronizar entre máquinas.
6. **Produtividade** — configure um launcher (Raycast/Alfred), um gerenciador de janelas (Rectangle) e atalhos de teclado (Karabiner-Elements).
7. **Editor/IDE e terminal** — escolha VS Code, Cursor ou um editor JetBrains, e um terminal moderno (iTerm2, Warp, Ghostty ou kitty).
8. **Contêineres e bancos de dados** — Docker Desktop ou OrbStack para contêineres; TablePlus/Sequel Ace para bancos de dados.

## 🚀 Por onde começar

1. **Atualize o sistema e instale as Command Line Tools:** `softwareupdate --all --install` e `xcode-select --install`.
2. **Instale o [Homebrew](https://brew.sh/)** — gerenciador de pacotes que resolve "como instalar X no Mac" para praticamente qualquer ferramenta de desenvolvimento.
3. **Leia o [Guia do Terminal da Apple](https://support.apple.com/guide/terminal/welcome/mac)** e configure o [Oh My Zsh](https://ohmyz.sh/) para um shell mais produtivo.
4. **Escolha seu editor:** [Visual Studio Code](https://code.visualstudio.com/) é o ponto de partida mais comum; experimente também o [Cursor](https://cursor.com/).
5. **Instale um terminal moderno:** [iTerm2](https://iterm2.com/) ou [Warp](https://www.warp.dev/) substituem o Terminal.app com abas, temas e integração com IA.
6. **Organize as versões de linguagem** com [asdf](https://asdf-vm.com/) (ou `nvm`/`pyenv` se preferir uma ferramenta por linguagem) em vez de instalar tudo globalmente.
7. **Crie seus dotfiles:** inspire-se em repositórios reais como o [mac-dev-setup do Nicolas Hery](https://github.com/nicolashery/mac-dev-setup) ou o [laptop da thoughtbot](https://github.com/thoughtbot/laptop) para montar o seu.
8. **Automatize com um `Brewfile`:** liste seus apps e ferramentas com o [Homebrew Bundle](https://github.com/Homebrew/homebrew-bundle) para reinstalar tudo com um comando quando trocar de máquina.

Seu primeiro `Brewfile` em 30 segundos:

```bash
xcode-select --install                     # ferramentas de linha de comando da Apple
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

brew bundle dump                           # gera um Brewfile com tudo que já está instalado
brew bundle --file=./Brewfile              # reinstala tudo a partir do Brewfile em outra máquina
```

## 🛠️ Ferramentas

> Terminal e shell

- [iTerm2](https://iterm2.com/) — O substituto mais popular do Terminal.app: abas, split panes, perfis e integração com shell.
- [Warp](https://www.warp.dev/) — Terminal moderno com blocos de comando, autocompletar por IA e colaboração.
- [Ghostty](https://ghostty.org/) — Terminal rápido e nativo, com renderização por GPU, lançado por Mitchell Hashimoto.
- [WezTerm](https://wezterm.org/) — Terminal multiplataforma configurável em Lua, com multiplexação embutida.
- [kitty](https://sw.kovidgoyal.net/kitty/) — Terminal acelerado por GPU, rápido e altamente configurável.
- [Starship](https://starship.rs/) — Prompt de shell rápido e customizável, funciona com zsh, bash e fish.
- [tmux](https://tmux.github.io/) — Multiplexador de terminal: várias sessões, janelas e painéis dentro de uma única conexão.

> Produtividade e janelas

- [Raycast](https://www.raycast.com/) — Launcher moderno que substitui o Spotlight, com extensões e comandos de IA.
- [Alfred](https://www.alfredapp.com/) — Launcher clássico do macOS, com workflows avançados (Powerpack pago).
- [Rectangle](https://rectangleapp.com/) — Gerenciador de janelas gratuito e open source, com atalhos de teclado para organizar telas.
- [Karabiner-Elements](https://karabiner-elements.pqrs.org/) — Customização avançada e gratuita do teclado no macOS.
- [BetterTouchTool](https://folivora.ai/) — Customização de gestos do trackpad, atalhos e automações. Ferramenta paga (com período de testes).
- [Amphetamine](https://apps.apple.com/us/app/amphetamine/id937984704) — Impede o Mac de dormir, com regras por app, rede ou horário. Gratuito, na Mac App Store.

> Gerenciamento de pacotes e ambientes

- [MacPorts](https://www.macports.org/) — Gerenciador de pacotes alternativo ao Homebrew, também open source.
- [asdf](https://asdf-vm.com/) — Gerenciador de versões plugável: Node, Ruby, Python e dezenas de outras linguagens numa ferramenta só.
- [pyenv](https://github.com/pyenv/pyenv) — Gerenciador de versões do Python, o mais usado para isolar interpretadores.
- [nvm](https://github.com/nvm-sh/nvm) — Gerenciador de versões do Node.js clássico e amplamente adotado.
- [fnm](https://github.com/Schniz/fnm) — Alternativa ao nvm escrita em Rust, bem mais rápida para trocar de versão do Node.
- [direnv](https://direnv.net/) — Carrega variáveis de ambiente automaticamente ao entrar numa pasta de projeto.
- [chezmoi](https://www.chezmoi.io/) — Gerenciador de dotfiles com templates, segredos e suporte a múltiplas máquinas.
- [GNU Stow (via Homebrew)](https://formulae.brew.sh/formula/stow) — Ferramenta clássica para organizar dotfiles com symlinks.

> Editores, apps e bancos de dados

- [Visual Studio Code](https://code.visualstudio.com/) — Editor de código gratuito mais usado atualmente, com enorme ecossistema de extensões.
- [Cursor](https://cursor.com/) — Editor baseado no VS Code com IA integrada ao fluxo de edição.
- [Sublime Text](https://www.sublimetext.com/) — Editor de texto rápido e leve, pago com uso ilimitado em avaliação.
- [JetBrains Toolbox App](https://www.jetbrains.com/toolbox-app/) — Gerencia as instalações das IDEs da JetBrains (IntelliJ, PyCharm, WebStorm etc.) no Mac.
- [Docker Desktop](https://www.docker.com/products/docker-desktop/) — Contêineres Docker no macOS com interface gráfica.
- [OrbStack](https://orbstack.dev/) — Alternativa leve e rápida ao Docker Desktop para contêineres e máquinas Linux no Mac.
- [TablePlus](https://tableplus.com/) — Cliente de banco de dados nativo para macOS, com suporte a múltiplos bancos. Gratuito com limitações; versão paga sem limites.
- [Sequel Ace](https://github.com/Sequel-Ace/Sequel-Ace) — Cliente MySQL gratuito e open source para macOS, sucessor do Sequel Pro.

> Utilitários do sistema

- [CleanMyMac](https://www.cleanmymac.com/) — Limpeza e manutenção do sistema. Ferramenta paga (com versão de teste).
- [AppCleaner](https://freemacsoft.net/appcleaner/) — Remove apps e todos os arquivos relacionados deixados no sistema. Gratuito.
- [Stats](https://github.com/exelban/stats) — Monitor de sistema gratuito e open source para a barra de menu (CPU, memória, disco, rede).
- [GitUp](https://gitup.co/) — Cliente Git visual, rápido e gratuito, pensado para quem já entende Git.

## 🤖 IA na prática

Configurar e manter um Mac de desenvolvimento é, no fundo, escrever e revisar scripts de shell — e isso é exatamente o tipo de tarefa em que um assistente de IA ajuda bastante, desde que você confira o que ele sugere antes de rodar.

**Para aprender**
- Peça para um assistente **explicar linha por linha** um `.zshrc` ou um script de instalação que você encontrou em um repositório de dotfiles, antes de copiar e colar no seu Terminal.
- Peça exemplos comentados de `Brewfile`, de aliases de zsh úteis e de funções de shell comuns (ex.: criar e entrar numa pasta em um comando só).
- Peça para comparar duas ferramentas (ex.: "iTerm2 x Warp x Ghostty" ou "Homebrew x MacPorts") com prós, contras e quando cada uma faz mais sentido.

**Para trabalhar**
- Use [GitHub Copilot](https://github.com/features/copilot), [Cursor](https://cursor.com/) ou [Claude Code](https://code.claude.com/docs/en/overview) para escrever e revisar scripts de setup, `Brewfile`s e automações de Terminal.
- Peça para a IA **gerar um script de bootstrap** do seu ambiente (instala Homebrew, roda `brew bundle`, clona seus dotfiles) e revise cada comando antes de executar — scripts que mexem no sistema merecem leitura linha a linha.
- Use assistentes de terminal como o [Warp](https://www.warp.dev/) (autocompletar e explicação de comandos por IA) para entender comandos complexos (`find`, `xargs`, `launchctl`) antes de rodá-los.
- Rode modelos de IA localmente no Mac com o [Ollama](https://ollama.com/), aproveitando a memória unificada dos chips Apple Silicon.

**Limites e boas práticas**
- **Nunca rode `sudo` ou scripts que mexem em permissões do sistema só porque a IA sugeriu.** Leia o script inteiro antes.
- IA pode sugerir comandos de outro sistema operacional (ex.: `apt` em vez de `brew`, caminhos de Linux) — confirme que o comando é mesmo para macOS.
- Não cole tokens, senhas ou chaves SSH em ferramentas de IA para "ajudar a debugar" — remova segredos antes de colar qualquer arquivo de configuração.
- Prefira ferramentas de IA com opção de rodar localmente (como o [Ollama](https://ollama.com/)) quando estiver lidando com scripts ou dados sensíveis da empresa.

Ferramentas de IA úteis no dia a dia de quem usa Mac para programar:
- [GitHub Copilot](https://github.com/features/copilot) — Autocomplete e chat com IA integrado ao editor.
- [Cursor](https://cursor.com/) — Editor com IA nativa, baseado no VS Code.
- [Claude Code](https://code.claude.com/docs/en/overview) — Agente de código da Anthropic no terminal, roda nativamente no macOS.
- [Ollama](https://ollama.com/) — Rode modelos de linguagem localmente no Mac, aproveitando a memória unificada da Apple Silicon.
- [prompts.chat](https://github.com/f/awesome-chatgpt-prompts) — Coleção aberta de prompts prontos para diferentes tarefas com LLMs.
